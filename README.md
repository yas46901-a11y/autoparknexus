## Overview
AutoPark Nexus is an intelligent parking assistant that detects, evaluates, and guides vehicles toward safer parking using real-time perception and risk-aware planning.

## Features
- Autonomous Parking Command Center
- Live Parking Lot Visualization
- AI Vision & Obstacle Detection
- Risk-based Spot Recommendation
- Route Planner (Grid + A*)
- Judge Demo Mode
